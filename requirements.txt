# ClipMind dependencies.
#
# Phase 1 (capture + storage):
pyperclip>=1.8,<2

# Phase 2 (local embeddings) -- fully offline after the one-time model download.
#
# These four are pinned to the newest combination that works with torch 2.2.2,
# which is the last PyTorch release with macOS x86_64 (Intel) wheels. There,
# sentence-transformers 6.x needs transformers >= 5.x, which needs torch >= 2.5,
# and torch 2.2.2 is linked against NumPy 1.x.
#
# On Linux / Apple Silicon / Windows, where torch >= 2.5 is available, you can
# relax these to:  numpy>=2  scipy>=1.14  sentence-transformers>=4  transformers>=5
numpy>=1.26,<2
scipy>=1.13,<1.14
transformers==4.48.3
sentence-transformers==3.4.1

# Phase 3 (time-aware hybrid search): no new dependencies.
# Time parsing is a hand-written stdlib `re` parser (search/timeparse.py) and
# keyword search uses SQLite's built-in FTS5/BM25. `dateparser` is deliberately
# not used: it eagerly reads "monday.com" as a weekday and a bare "5pm" as a
# filter, which is exactly the misfire Phase 3 must avoid.

# Phase 4 (privacy filters + config): no new dependencies.
# Secret detection is regex + validation, and config.toml is read with the
# Python 3.11+ standard-library `tomllib`.

# Phase 5 (desktop UI): popup, tray icon and global hotkey.
#
# PySide6 is pinned to the 6.7 line: it is the newest release verified to
# install on macOS x86_64 (Intel) with Python 3.12 and torch 2.2.2. `pynput`
# pulls in pyobjc-framework-Cocoa/Quartz on macOS, which also powers the
# frontmost-app detection and the Input Monitoring permission check.
PySide6>=6.7,<6.8
pynput>=1.7,<2

# Development / tests:
pytest>=8.0
# pytest-qt drives the offscreen popup smoke test; without it that test skips.
pytest-qt>=4.4,<5

# Phase 6 (benchmark + packaging): no new *runtime* dependencies.
#   * benchmarks/bench_search.py uses the embedding stack above plus numpy.
#   * scripts/make_icon.py needs Pillow (already pulled in by torchvision/torch).
#   * the macOS bundle needs PyInstaller; it is declared as the `build` extra
#     (`pip install -e ".[build]"`) and installed for you by
#     scripts/build_macos.sh.
pillow>=10.0
